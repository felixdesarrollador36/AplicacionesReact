# Sistema de Gestión - Mente Tester

Este proyecto permite administrar estudiantes y generar comprobantes de pago automáticos para la academia Mente Tester.

## Estructura
- backend/: Node.js + Express + MongoDB
- frontend/: React.js

## Funcionalidades principales
- Registro y gestión de estudiantes
- Generación de recibos PDF
- Envío automático por WhatsApp
- Historial de pagos
