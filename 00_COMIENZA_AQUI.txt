🆘 SI ALGO FALLA:

Problema: "npm not found"
Solución: Instala Node.js desde https://nodejs.org

Problema: "Port 8081 already in use"
Solución: npm start --clear

Problema: La app no se muestra
Solución: 
  1. npm start --clear
  2. Presiona 'w' para web
  3. Si continúa, lee QUICK_START.md

Problema: No veo documentos
Solución: Agrega archivos PDF en tu dispositivo primero
